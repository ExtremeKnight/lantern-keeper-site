Everywhere else

ChromeOS, Xbox (in Microsoft Edge) and any other device with a modern browser: play the web version. It works with touch, mouse, keyboard and controllers.

Older computers and devices

The apps need a current system: Windows 10 or 11 (64-bit), macOS 11 Big Sur or newer, a 64-bit Linux PC, Android 7.0 or newer, iOS 15 or newer. On anything older, play the web version: it is the same game, keeps your progress with a free account, and can be installed like an app.

Windows 7, 8 and 8.1

  1. Install Google Chrome (version 109, the last for these systems) or Firefox ESR (115), if you don't have one of them.
  2. Open the web version in it.
  3. To keep it like an app: in Chrome, open the menu (⋮) and choose Install Lantern Keeper (or Save and share > Create shortcut, ticking Open as window).

There is no installer for these systems: Microsoft and the browser makers no longer send them security fixes, and an app on them would not get any either.

Windows 10, 32-bit

  1. Play the web version in Edge or Chrome, and install it from the browser's menu (Apps > Install this site as an app in Edge).

A 32-bit installer is coming in version 0.30. To check which you have: Settings > System > About > System type.

macOS 10.15 Catalina and older

  1. Open the web version in Safari, Chrome or Firefox.
  2. To keep it in the Dock: in Chrome, menu (⋮) > Install Lantern Keeper; in Safari on macOS 14 and later, File > Add to Dock.

Android 5 and 6

  1. Update Chrome and Android System WebView in the Play Store.
  2. Open the web version in Chrome, then menu (⋮) > Add to Home screen.

iPhone and iPad

  1. Open the web version in Safari.
  2. Tap Share, then Add to Home Screen. It opens full screen, like an app. (iOS 15 or newer is best; older iOS may run it more slowly.)

Linux on ARM (Raspberry Pi 4 and 5, ARM laptops), ChromeOS

  1. Play the web version in Chromium, Chrome or Firefox, and install it from the browser's menu.

ARM Linux builds are coming in version 0.30. On a Chromebook the web version is the best choice.

If the game opens but looks wrong or runs slowly on an older system, set Settings > Graphics to Low, and tell us what you play on: exenovaph@gmail.com. Every report helps us mark systems as tested.
